# Corrida Neon

Protótipo de jogo de navegador com três pistas, turbo, desafios, garagem e controles para celular. Código estático em HTML, CSS e JavaScript.

Projeto de Pedro Tiago desenvolvido com apoio de IA.

[Experimentar demonstração](https://pedro-tiago-sites.sabedoriameditativa.chatgpt.site/projetos/corrida-neon/) · [Portfólio](https://github.com/sabedoriameditativa-ops/pedro-tiago-portfolio)

## Executar localmente

Com Python 3 instalado, execute nesta pasta:

```sh
python3 -m http.server 8000
```

Abra `http://localhost:8000`. Não há dependências de build para instalar.
